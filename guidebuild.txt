DEVolf build guide
==================

Targets
-------
x64: Python 3.11 x64, PySide6/Qt6, x86_64 MinGW GCC.
x86: Python 3.8 x86, PySide2/Qt5, i686 MinGW GCC.
Use a complete Python installation with pip and venv, or supply an existing
runtime using -PythonExecutable. Git, GitHub CLI, CMake and Ninja are required.

Authenticate once with gh auth login. Read access is required for the private
majidnow/BeachEye and majidnow/wolfeye dependency checkouts. Company sources
are cached outside the repository and are never published with DEVolf.

Build
-----
.\build.ps1 -Architecture x64
.\build.ps1 -Architecture x86

Outputs: Dist/DEVolf-x64.exe and Dist/DEVolf-x86.exe.
A running output is preserved; the build prints an alternate file name.
Dependencies, the BeachEye DLL, all tests, packaging, PE architecture and
startup are checked separately for each target. WolfEye algorithms run in
Python; wolfeye_core.dll is not built, loaded or packaged.

Update native support dependencies
---------------------------------
.\build.ps1 -Architecture x64 -UpdateBeachEye -UpdateWolfEye
.\build-native.ps1 -Architecture x86 -UpdateBeachEye -UpdateWolfEye

Without update switches, recorded manifests are reused. WolfEye master ports
are pinned to 7e58f4af439c6fa9c9db51e4558936264401732a; an algorithm update
requires a reviewed Python port and parity tests. Updating support headers
alone does not rewrite the Python algorithms.

Toolchain selection
-------------------
DEVOLF_GCC_BIN selects the compiler directory and must match -Architecture.
x64 defaults to C:/msys64/ucrt64/bin, then PATH.
x86 checks %LOCALAPPDATA%/DEVolf/Toolchains/mingw32/bin and C:/mingw32/bin,
then PATH. Ninja may be installed separately on PATH.

Advanced
--------
.\build.ps1 -Architecture x86 -PythonExecutable 'C:/Python38-32/python.exe'
.\build.ps1 -Architecture x86 -Wheelhouse 'D:/Wheelhouse'
.\build-native.ps1 -Architecture x64 -OutputDirectory 'D:/BuildOutput'

The standard environments are .venv (x64) and .venv38-x86 (x86). A prepared
x86 embedded runtime at %LOCALAPPDATA%/DEVolf/Toolchains/Python38-x86-embedded
can be used automatically when the x86 environment does not exist.
Generated build/ and output/ folders may be deleted after a build. Keep
sessions/, scenario JSON files, assets, tests and the external toolchain cache.
32/64 signal samples per cycle is independent of the EXE architecture.
