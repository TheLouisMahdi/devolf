BeachEye v50 - SIGNAL payload diagnostics
Runtime reference: WolfEye master 7e58f4a, INFO flags & 0x02.
Flag set: 32 float32 samples/channel at 1600 Sa/s; 1280/1536 bytes,
or fixed 2560/3072-byte buffers (only the first 1280 bytes are plotted).
Flag clear: 64 float32 samples/channel at 3200 Sa/s; 2560 or 3072 bytes.
Samples are channel-major, with 10 plot channels and optional Vbat/lm35.
After Get signal, the exact raw payload and a JSON metadata file are saved to:
%LOCALAPPDATA%\DEVolf\diagnostics\signal-response.bin
Get ADC saves adc-response.bin and .json in the same directory (uint16
half-cycle voltage/current blocks). Each command overwrites its own files.
Attach the relevant .bin
along with the .json for a verified waveform decoding diagnosis.
BeachEye ABI 12 and WolfEye core ABI 1 are required. Rebuild both DLLs
and the EXE together. Signal decoding runs in wolfeye_core.dll.
If the supplied device uses a different SIGNAL wire layout, do not guess
the conversion. Compare actual raw payload against its firmware producer.
